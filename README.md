# Laboratorio 9 - Teoría de Probabilidades

Este repositorio almacena los archivos de Jupyter Notebook (.ipynb) de la etapa 5, representando nuestros casos sobre la simulación del album real.

## Distribución de los Archivos

[Pregunta 1](laboratorio9_pregunta1.ipynb): ¿Cuál es la probabilidad de completar el álbum con 2 cajas y una tasa de intercambios de K=4? 

[Pregunta 2](laboratorio9_pregunta2.ipynb): ¿Cuál es la probabilidad de completar el álbum únicamente con 3 cajas? 

[Pregunta 3](laboratorio9_pregunta3.ipynb): ¿Cuál es la probabilidad de completar el álbum con exactamente 140 sobres? 

[Pregunta 4](laboratorio9_pregunta4.ipynb): ¿Existe una diferencia en abrir 2 cajas de 104 sobres que contienen 7 estampas, comparado con abrir 182 sobres de 8 estampas cada una?

[Pregunta 5](laboratorio9_pregunta5.ipynb): Tomando en cuenta el modelo estándar ¿cuántas cajas se deberían de abrir para llenar el álbum dos veces?
